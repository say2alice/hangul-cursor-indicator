This release fades out the pointer badge when the pointer stops, and places the badge slightly lower next to the I-beam.

## Changes

### Added

- The badge next to the pointer appears only while the pointer moves. When you stop the pointer, the badge fades out over 0.3 seconds after 0.7 seconds, and it appears again as soon as you move the pointer. While the pointer is still, switching the input mode does not bring back the pointer badge, and the caret badge shows the mode instead ([GitLab !11](https://gitlab.way2java.net/jangb/hangul-cursor-indicator/-/merge_requests/11))

### Changed

- The pointer badge is placed 2px lower next to the I-beam. With the Yaru I-beam at size 24, the gap is 4px to the right and 6px down ([GitLab !10](https://gitlab.way2java.net/jangb/hangul-cursor-indicator/-/merge_requests/10))

### Fixed

- Fixed an extension error (`has been already disposed`) that could be left in the shell log at logout ([GitLab !12](https://gitlab.way2java.net/jangb/hangul-cursor-indicator/-/merge_requests/12))

## Upgrade

Download the zip below, reinstall it with `--force`, and then log out and log back in.

```bash
gnome-extensions install --force hangul-cursor-indicator-1.1.0.shell-extension.zip
```

The requirements and known limitations are the same as in v1.0.0. See the [README](https://github.com/say2alice/hangul-cursor-indicator/blob/main/README.md) for details.
