포인터를 멈추면 배지가 서서히 사라지고, 배지가 I빔보다 조금 아래에 놓이도록 바꾼 릴리스입니다.

## 변경 사항

### 추가

- 포인터 옆 배지는 포인터를 움직일 때만 나타납니다. 포인터를 멈추면 0.7초 뒤 0.3초 동안 서서히 사라지고, 다시 움직이면 바로 나타납니다. 멈춘 동안에는 한/영을 바꿔도 포인터 옆 배지는 나오지 않고 캐럿 옆 배지로 알립니다(!11)

### 변경

- 포인터 옆 배지를 I빔보다 2px 아래에 놓습니다. 크기 24 Yaru I빔에서 간격이 오른쪽 4, 아래 6입니다(!10)

### 수정

- 로그아웃할 때 셸 로그에 확장의 오류(`has been already disposed`)가 남을 수 있던 문제를 고쳤습니다(!12)

## 업그레이드

아래 zip을 내려받아 `--force`로 다시 설치한 뒤, 로그아웃했다가 다시 로그인합니다.

```bash
gnome-extensions install --force hangul-cursor-indicator-1.1.0.shell-extension.zip
```

요구 환경과 알려진 제약은 v1.0.0과 같습니다. 자세한 내용은 [README](https://gitlab.way2java.net/project/hangul-cursor-indicator/-/blob/main/README.md)를 봅니다.
