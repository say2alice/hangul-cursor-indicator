보조 모니터의 최대화 창과 전체 화면 창 위에서 배지가 깜빡이던 문제를 고친 릴리스입니다.

## 변경 사항

### 수정

- 상단 바가 없는 보조 모니터에서 최대화한 창과 F11 전체 화면 창 위에서 포인터 배지와 캐럿 배지가 깜빡이던 문제를 고쳤습니다. 이런 창은 셸이 화면 합성을 건너뛰고 바로 내보내는데(직접 스캔아웃), 이제 배지가 보이는 동안에는 합성하도록 합니다(!7)
- 전체 화면 창에서도 포인터가 텍스트 커서이거나 캐럿이 있으면 배지를 표시합니다. 동영상 재생처럼 앱이 포인터를 숨기면 배지도 함께 숨습니다(!7)

## 업그레이드

아래 zip을 내려받아 `--force`로 다시 설치한 뒤, 로그아웃했다가 다시 로그인합니다.

```bash
gnome-extensions install --force hangul-cursor-indicator-1.0.1.shell-extension.zip
```

요구 환경과 알려진 제약은 v1.0.0과 같습니다. 자세한 내용은 [README](https://gitlab.way2java.net/project/hangul-cursor-indicator/-/blob/main/README.md)를 봅니다.
