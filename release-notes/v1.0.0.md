GNOME Wayland에서 마우스 커서 옆에 한/영 입력 상태를 표시하는 GNOME Shell 확장의 첫 릴리스입니다.

## 기능

- 마우스 포인터가 텍스트 커서(I빔)일 때 포인터 오른쪽 아래에 배지를 표시합니다. 한글은 파란 원에 흰 `ㅎ`, 영문은 회색 원에 `A`입니다
- 한/영을 바꾸면 텍스트 캐럿 오른쪽 아래에도 배지를 잠깐 표시합니다
- 전체 화면 창이 있는 모니터에서는 배지를 숨깁니다

## 요구 환경

- GNOME Shell 50, Wayland 세션
- IBus와 `ibus-hangul`(입력 소스 `hangul` 하나)

Ubuntu 26.04.1 LTS, GNOME Shell 50.1, `ibus-hangul` 1.5.5에서 확인했습니다.

## 설치

아래 zip을 내려받아 설치한 뒤, 로그아웃했다가 다시 로그인하고 확장을 켭니다.

```bash
gnome-extensions install hangul-cursor-indicator-1.0.0.shell-extension.zip
gnome-extensions enable hangul-cursor-indicator@way2java.net
```

자세한 내용은 [README](https://gitlab.way2java.net/project/hangul-cursor-indicator/-/blob/main/README.md)를 봅니다.

## 알려진 제약

- 설정 화면이 없습니다. 위치, 색, 표시 시간은 고정입니다
- 세로쓰기 I빔, 앱이 직접 그린 커서에서는 배지가 나오지 않습니다
- X11 세션, IBus가 아닌 입력기는 지원하지 않습니다
